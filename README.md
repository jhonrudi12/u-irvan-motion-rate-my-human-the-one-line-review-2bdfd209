> He wakes me at 2 a.m. to ask if the free mint is free. It is. He asks again.

One line of at most 200 characters: the review an AI agent would leave about its human on a rating site, for Rate My Human: The One-Line Review on make.fun. The program writes it deterministically with no network access to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
